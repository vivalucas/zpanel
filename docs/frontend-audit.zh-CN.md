# React 重构自查（2026-09-13）

## 入口脚本体积优化（2026-09-24）

排查生产构建的模块组成后，确认入口静态引入了登录表单，以及共享组件文件中的图片上传和 HTML 净化依赖。现将登录页按路由延迟加载，把 `SafeHtml`、`ImageUpload` 拆为独立模块；构建器只对 React、React DOM、Scheduler 这组单向依赖的运行时指定独立分组，业务组件仍使用默认自动拆分。没有提高体积告警阈值，也没有把所有第三方依赖强制塞进一个 vendor 包。

普通构建入口从约 1,100 KB 降至约 363 KB；React 运行时约 219 KB，共享代码约 232 KB，最大脚本低于默认 500 KB 告警线。普通与可选 PWA 构建均无体积告警。生产构建下 15 项 Playwright 浏览器用例全部通过，覆盖登录、首页、设置、文件、备份、权限和手机布局；TypeScript、ESLint、9 项 Vitest 与专项回归通过。分包会增加首次访问时的并行请求数，但登录、上传和净化代码只在用到的页面加载。

## 视觉与入口复查（2026-09-24）

按 [视觉设计规范](ui-design.zh-CN.md) 对照重构前 Vue 首页与现有 React 页面，保留用户熟悉的**位置和图标大小**，并使用新的玻璃材质。旧版名称与时钟并排、搜索框在下、分组纵向排列、工具在右下；默认 70px 小图标，详情卡横排。上下边距仍以百分比、左右边距以像素保存；React 默认值已恢复为旧版的 10%、10%、5px 和小图标。已有用户配置仍按其保存值展示，若近期 React 版本保存过 36/32 等边距，可在风格设置中按新标注的单位调整。

| 检查点 | 发现与处理 |
|---|---|
| 页面入口 | 首页顶部的独立工具栏移至旧版右下位置；添加与排序回到所属分组标题旁。设置页只留一个返回首页入口。未开放公开访问时，登录页不再提供会绕回登录页的按钮；从公开首页进入登录页时保留返回入口，并可在登录前切换语言。 |
| 文字与交互 | 详情卡有描述才显示副标题，不再把 URL 当描述；关闭本地应用搜索后只提示网页搜索。CPU 核数按界面语言显示。排序状态下点击应用不再意外打开编辑框，菜单也暂时禁用。 |
| 风格一致性 | 浅色、深色、自定义壁纸均复用玻璃变量；检查搜索框、监控、两种导航样式、设置页与登录页。壁纸上的搜索选择器、分组操作和导航文字使用浅色；Vue 旧默认文字色 `#1f2937` 按主题自动适配，深色图标文字提亮。 |
| 布局与功能 | 1440px 桌面和 390px 手机实测小图标底座均为 70px，手机无横向溢出；详情卡、壁纸和深色设置页人工截图复核。公开访问、权限、登录、导航编辑、搜索、键盘排序、导入导出与设置保存由端到端用例覆盖。 |

本轮生产构建、TypeScript、ESLint、9 项 Vitest、导航与导入导出专项回归及 15 项 Playwright 浏览器用例通过；`git diff --check` 通过。视觉复查时尚存的入口体积告警已由上节优化解决。浏览器用例运行在隔离的 Go 服务和临时 SQLite 数据库上，截图复核使用 Chromium。真实 Docker 容器、Safari/Firefox、触屏设备以及各种用户自定义 CSS/壁纸组合仍需对应环境验收。重构前的既有验收记录如下，保留以便追溯。

## 本次发现并修复

- 手工拆分第三方依赖在导入变化后出现循环依赖，构建成功但浏览器白屏；移除不稳定的手工分包，使用 Vite 默认共享依赖拆分，保留页面延迟加载并通过生产浏览器回归。
- HTTP 局域网缺少 `crypto.randomUUID` 时登录页崩溃；统一改用可在 HTTP 使用的随机 ID。
- 旧请求或确认回调在切换账户后继续影响当前会话；请求绑定会话并丢弃过期响应，个人资料保存不再切回旧账户。
- 默认引擎以索引存储，删除它之前的引擎时会错位；现在同步调整索引，并恢复首页默认引擎持久化与图标展示。
- 保存期间编辑及外观回填可能覆盖输入；保存期间禁用表单，成功刷新后才解除脏标记，失败保留输入。外观、组件、站点设置增加未保存离开提醒。
- 项目编辑框会随分组查询刷新而重新初始化；改为打开编辑框时初始化一次。
- 文件末页删除后分页入口消失，引用替换只能选择当前页；保留分页入口并增加独立的替换来源与分页选择。
- 自定义脚本随整个站点对象变化重复执行，hash 安全模式不能即时响应；拆分标题、CSS、JS 更新，并对脚本恢复执行整页重载。
- 全局加载图标参与按钮无障碍名称，快速失败后的按钮可能残留 `loading` 名称；通过 Ant Design 公开配置提供装饰性加载图标，保持按钮名称稳定。
- 不存在的设置路径误报 403；现在按实际权限或不存在分别显示 403/404。
- 可选 PWA 构建生成的根路径资源未被 Go 提供；增加明确资源路由，避免开放任意工作目录文件。
- 贡献指南与更新日志遗漏重构和测试说明；同步 README、前端说明、贡献指南、更新日志与本自查记录。
