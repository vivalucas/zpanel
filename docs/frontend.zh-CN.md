# React 前端开发

ZPanel 前端使用 React、TypeScript、Vite 和 Ant Design。后端仍为 Go / Gin，前端编译产物仍输出到 `dist`，Docker 将其复制到 `/app/web`。页面采用 Hash 路由，不需要额外配置 SPA 路由回退。

## 开发与验证

```bash
pnpm install --frozen-lockfile
pnpm dev
```

另开终端启动 API：

```bash
cd service
go run main.go
```

前端默认端口为 `1002`，代理 `/api` 和 `/uploads` 到 `6521`。可通过 `VITE_APP_API_BASE_URL` 调整开发代理目标。

```bash
pnpm type-check
pnpm lint
pnpm test
pnpm test:review
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

浏览器测试需要 Go。测试脚本自动编译后端，在系统临时目录创建数据库与配置，使用 `16521` 端口提供真实 API 和 `dist` 静态页面，退出时清理。运行前先执行 `pnpm build`。测试不会使用 `service/data`；Docker 连接指向一个不存在的 socket，避免测试操作宿主机容器。

## 目录结构

- `src/app`：入口、路由、会话边界、全局主题和布局样式。
- `src/features/auth`：登录和验证码。
- `src/features/home`：导航首页、卡片编辑和监控显示。
- `src/features/settings`：外观、分组、搜索与监控、文件、备份、账号、账号管理、Docker、站点和关于页面。按页面延迟加载。
- `src/components`：共享布局、上传、错误状态和支持键盘操作的拖拽容器。
- `src/lib`：HTTP 协议、数据查询、反馈和纯格式化逻辑。
- `src/locales`：i18next 语言资源；新增界面文案提供中英文，其他语言缺失项回退到英文。
- `src/utils`：导航 URL 校验和备份协议。
- `tests/e2e`：使用临时 Go API 的浏览器回归；Docker 成功路径、故障注入与多页文件数据使用模拟响应。

## 加载边界

首页、登录页与设置页按路由延迟加载；设置子页面继续按需加载。`SafeHtml` 的 DOMPurify 和 `ImageUpload` 的上传控件位于独立模块，避免应用外壳提前加载这些页面功能。`vite.config.ts` 只将 React、React DOM 与 Scheduler 归入一个运行时文件，其余依赖交给 Rolldown 自动拆分。修改加载边界或分包规则后，必须运行生产构建及 `pnpm test:e2e`：仅构建成功不能证明页面不会因依赖循环而白屏。

## 组件与主题约定

基础控件使用 Ant Design。颜色、圆角、控件高度与字体在 `Providers.tsx` 的 `ConfigProvider` 中统一定义，页面通过 `--surface`、`--canvas`、`--text`、`--muted`、`--border`、`--primary` 等变量使用同一套主题。

导航卡片、时钟和监控布局为业务组件。无壁纸时背景与文字跟随主题；壁纸首页按可见明暗自动配色，用户显式设置的导航文字色同时用于标题与描述。玻璃材质、首页布局、壁纸模式、两种图标布局和设置页层级遵循[视觉设计规范](ui-design.zh-CN.md)。避免覆盖 Ant Design 内部 DOM 层级；需要定制控件时，优先使用组件 token 和公开属性。装饰图标从无障碍名称中隐藏，功能按钮提供可读标签。

设置页通过统一的 `Section` 组织，表单采用一致的间距和保存按钮。手机使用顶部分类选择器；桌面采用一体化悬浮玻璃窗口。风格与站点设置的底部保存栏独立占据布局空间，上方表单滚动；其他页面按独立表单提供统一样式的操作区。`prefers-reduced-motion` 下禁用额外动效。

## 版本号

`package.json` 与 `service/assets/version` 使用相同的发布版本。前端构建脚本校验两者一致，并将发布版本用于关于页面和配置导出，不再使用构建日期作为前端版本。发布 tag 使用 `v` 前缀。

## 页面文案

使用准确的功能名称、操作动词和结果提示。删除口号、装饰性英文和重复说明，不添加未经确认的产品定位。仅保留影响操作的说明（如保存范围、删除后果、备份范围和恢复方式）。管理员配置的站点标题、副标题和页脚按配置显示。

## 数据与会话

- TanStack Query 管理后端数据、加载状态、刷新、错误及监控轮询。
- Zustand 只持久化主题、语言、内外网模式和账号会话。
- 每次切换账号创建独立的 QueryClient，取消旧查询并清除旧缓存。
- 请求使用后端要求的 `token` / `lang` 请求头，并传递查询取消信号。
- HTTP 成功但业务 `code` 非零时抛出 `ApiError`。仅 `1202` 表示缺少配置并使用默认值；数据库错误保持可见。
- 读取失败通过共享 `QueryError` 呈现本地化摘要和重试；需要排障的管理员页面可折叠显示服务端原文。容器、账号与搜索/监控配置首次读取失败时替换内容，已有数据刷新失败时保留上次结果并提示可能过期；局部数据失败时保留其他可用内容。不能把失败渲染成空列表。
- 写操作不自动重试。备份导入使用稳定的 `requestId` 重试同一请求，避免重复追加。
- 导航由 `getNavigation` 一次读取分组和应用，避免随分组数增加请求。外观已知字段在前后端校验；旧损坏值临时回落为默认值并提供修复入口，明确保存后才写回。路由异常提供本地化恢复页和安全模式入口。
- 权限入口根据服务端 `getAuthInfo` 返回的角色与访问模式展示，服务端继续负责最终鉴权。

## 功能与边界

导航支持增删改、分组、图片/文字/Iconify 图标、内外网地址、三种打开方式、搜索、菜单与按分组拖拽排序。排序也支持聚焦手柄后使用空格和方向键；排序时点击应用不执行打开或编辑，完成后恢复正常点击。

空分组仅提供「添加第一个应用」，配置导入统一从「设置 → 导入与导出」进入。项目可只填内网地址，至少一个有效地址；标题最多 200 字符。卡片使用原生链接，普通点击遵循内外网模式、地址缺失回退与已保存的打开方式，中键及修饰键保持浏览器行为。应用右键和「更多操作」共用一个菜单：按表单的「地址」「内网地址」分别操作，未填写的地址不显示；主操作遵循已保存的打开方式，新标签页/内嵌快捷操作仅覆盖本次打开，复制相对地址时解析成完整网址。Shift＋右键及页面空白处保留浏览器菜单，触屏通过可见的「更多操作」进入。访客仅可打开和复制；编辑/删除沿用原权限，删除仍须确认。当前分组排序时应用菜单不可用。分组删除显示应用数量，可选择迁移至其他分组，服务端在事务中完成；最后一个分组禁用删除并说明原因。

菜单支持键盘打开、方向键选择和 Esc/Tab 退出并恢复触发位置；编辑跨分组后仍按稳定应用 ID 恢复焦点。菜单在外部点击、页面滚动、窗口变化、应用被过滤、离页或切账号时关闭。复制仅在写入成功后提示成功，剪贴板不可用或拒绝时提供已选中的完整地址供手动复制，离页后的迟到结果不再弹窗。内嵌继续保留限制提示与外部打开入口，不依赖 iframe 加载事件判断成功，不放宽 sandbox。

文件支持个人与公共图库、上传、设置壁纸、引用查询、引用替换与删除。导入导出覆盖导航与面板外观配置，不包含图片文件、账号密码或搜索/监控模块配置。

图片上传预检格式和 10 MiB 单文件上限，显示逐文件状态，失败可重试。成功上传后刷新失败不会触发重复上传；单选上传期间不可另选文件。导入显示新增或覆盖的分组/应用数量，覆盖所需当前数据读取失败时禁用操作并提供重试。

外观、个人资料和项目编辑在图片上传完成前禁用保存，保存期间禁用上传；favicon 获取结果只写回仍匹配发起目标的图标草稿。备份文件连续选择时只接受最新读取结果，覆盖确认期间冻结文件和选项。

监控在页面可见时每 5 秒轮询。Docker 管理支持资源快照、启动、停止、重启、暂停、恢复和日志；实际容器操作需要后端可连接 Docker。

访客监控须公开账号同时开启监控和访客显示，服务端同步限制。私网 favicon 默认拒绝，管理员可在部署配置中列出精确源，普通账号只访问公网，详见 [环境配置](../handbook/07-environment.md)。关于文案关闭自动识别裸链接并显示最多 32768 字符，明确 Markdown 链接仍可用。

站点设置保留自定义 CSS / JavaScript。HTML 页脚先经过 DOMPurify；自定义 JavaScript 作为管理员明确配置的功能执行。地址添加 `?safeMode=1` 可跳过自定义 CSS / JavaScript。

## 重构范围

原 Vue、Pinia、Naive UI 组件与构建依赖已移除。没有并行维护旧前端，也不提供旧浏览器本地状态迁移。Go 业务接口与部署产物结构保留；修正了缺少数据时的错误码，以支持新账号首次进入。

## 页面入口与编辑约定

首页设置图标进入 `/#/settings/appearance`；设置和内外网工具位于桌面右上角、手机右下角。首次编辑提示会展示组内工具，关闭后保存在当前浏览器；桌面悬停或键盘聚焦仍可显示，触屏保持可见。桌面设置页使用侧栏，手机使用页首选择器。导航项目在所属分组标题旁添加、编辑、排序；分组在「导航分组」管理。搜索引擎与监控卡片位于「搜索与监控」。管理员额外看到用户、Docker、站点设置，普通用户直接访问这些 URL 返回 403；不存在的设置页面返回 404。匿名公开访问只显示导航及登录入口。未开放公开访问时，登录页不提供会绕回登录页的“返回首页”；从公开首页进入时才提供。登录前可以切换语言。

外观、搜索与监控、站点设置、个人资料均需点「保存」。失败时保留当前输入；保存期间禁用表单；切换页面时提示放弃未保存修改，刷新或关闭页面使用浏览器原生提示；个人资料和密码草稿在切换账号前同样提示。主题、语言、内外网模式是浏览器偏好，即时生效。登录用户从首页选择搜索引擎会保存为默认引擎，失败回滚选择以便重试；访客选择仅在当前页面生效。新密码限 6–72 个 UTF-8 字节，登录上限同为 72 字节，避免保存后无法登录。

文件引用替换可独立选择「我的文件」或「公共图库」并翻页。替换会修改自己有权管理的引用，不会自动删除原图。文件图库与外观配置保存不同：图片上传只生成文件，外观页面上传壁纸后仍需保存。

## HTTP 与自定义代码

普通局域网 HTTP 可用于登录、编辑和导入。请求 ID 使用 `crypto.getRandomValues` 生成，不能依赖仅安全上下文提供的 `crypto.randomUUID`。页面内请求使用 `useSessionRequest`，同时绑定会话和页面生命周期；卸载取消请求及确认框，响应与 JSON 读取完成后再次检查会话和取消状态。显式匿名登录同样绑定发起会话，旧回调不能在切账号或离页后登录或导航。调用方取消仍有效；取消客户端等待不承诺回滚服务端已完成的写入。

自定义 CSS 随内容变化更新；相同 JavaScript 不会因为修改标题、主题或重新取站点数据而重复执行。修改 JavaScript 会执行新的内容，但无法撤销旧脚本已经添加的计时器和事件监听，彻底替换后应刷新页面。`/?safeMode=1#/settings/site` 或 `/#/settings/site?safeMode=1` 可恢复设置；已经执行脚本时，进入安全模式会重新加载以清除旧副作用。仅支持管理页面中的数据库自定义配置，不再默认引用不存在的 `/custom/index.css` 和 `/custom/index.js`。

## 可选 PWA

构建环境设置 `VITE_GLOB_APP_PWA=true` 可生成清单与 service worker，默认关闭。Go 显式提供清单、注册脚本、worker 和图标路径；worker 内联运行库。生产浏览器安装需要 HTTPS（localhost 除外），普通 HTTP 局域网仍可直接访问应用。PWA 缓存静态界面，不提供离线业务数据或离线写入。本轮验证了 PWA 构建和资源路由，未验证操作系统安装和升级生命周期。

完整功能对照、回归范围及尚未验证的集成见 [React 重构自查](frontend-audit.zh-CN.md)。
