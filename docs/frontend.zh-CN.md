# React 前端开发

React/TypeScript/Vite/Ant Design，Go/Gin API；Hash 路由无需 SPA 回退。产物 `dist` 在容器内为 `/app/web`。本页维护前端行为；视觉参数见 [UI](ui-design.zh-CN.md)，实体/接口语义见 [05](../handbook/05-data-design.md)/[06](../handbook/06-api-design.md)，操作入口见 [13](../handbook/13-operation-guide.md)，设计原因见 [11](../handbook/11-decisions.md)。

## 开发与验证

安装、双服务启动、检查/构建命令见 [贡献指南](../CONTRIBUTING.md#development-setup)，固定工具链/代理见 [07](../handbook/07-environment.md)。浏览器回归使用生产构建、隔离 Go/SQLite，不连接开发数据或宿主 Docker；测试按[前端验收](frontend-audit.zh-CN.md)选取，隔离规则见 [10](../handbook/10-quality.md#隔离与证据)。

## 目录结构

`src/app` 管路由/会话/主题，`features/{auth,home,settings}` 管页面，`components` 管共享表面/上传/键盘拖拽，`lib` 管请求/查询/反馈，`utils` 管 URL 与备份协议，`locales` 管 i18next，`tests/e2e` 管浏览器回归。新增文案提供中英，其余缺项回退英文；语言质量不以 key 数量判定。

## 加载边界

- 路由及设置子页延迟加载，`SafeHtml`/DOMPurify、`ImageUpload` 独立。`vite.config.ts` 仅手动合并 React/React DOM/Scheduler，其余由 Rolldown 拆分；更改后须构建并跑生产浏览器回归，构建成功不证明无依赖环白屏。
- 页面代码与鉴权并行，已完成导入直接复用；个人数据等新鉴权。编辑/菜单/拖拽在操作时加载，普通导航不挂载拖拽传感器，监控按配置加载。等待可取消，排序占位不聚焦，迟到结果不重开。失败只替换局部区域，保留首页，提供关闭/取消及刷新；先释放弹窗焦点陷阱再回原触发点，自动监控回首页名称。
- 鉴权/首页代码/首次外观等待使用独立 `HomeStartupShell`：通用标题、共享 `HomeClock` 的真实时钟、静态占位/阶段说明（身份/页面/导航）；仅读本机语言/主题及不含身份、URL的背景明暗提示，不读快照/个人查询，不显示个人壁纸、页脚或账号入口。HTML在模块下载前读取提示，无提示首页先用深色；首页提示与非首页初始文档主题底色分开，直开登录/设置再进入首页也恢复提示。首次壁纸可展示前保持可读壳，导航/外观/搜索及图片加载仍并行，正式人工字色只在首页呈现；后续重验换图不重新挂壳或卸载编辑等交互，同图重分析不隐藏图。鉴权后根据实际合成背景更新本机明暗提示，跨域不可分析保守用深色，无图/坏图恢复默认渐变。占位不可操作，时钟不进 live region、清理定时器；正式时钟仍支持秒钟/配色。读取失败壳内重试，代码失败保留壳并刷新页面；登录/设置不用该壳，迟到结果不得带回首页。仍需取得 HTML/脚本，无离线鉴权。
- 外观先呈现，导航分区读取/重试；壁纸原图下载及解码总预算15秒，失败/超时保留配置URL并呈现主题渐变与可用首页，超时原图不迟到接管，重进或新上下文可重试。原图解码就绪后，单独的CORS取样最多等1.5秒再走不可分析回退，迟到有效分析可接管。普通模式解码即展示；首次自动对比等遮罩或回退后一起展示，避免先露出亮原图。首次失败不能当空数据，暂时刷新失败保留缓存。鉴权拒绝隐藏缓存并关闭菜单/编辑/排序/iframe，恢复不重开。Ant Design 语言按需加载、英文兜底，迟到成功/失败均服从最新选择。
- 首页快照仅新鉴权后恢复同账号/角色的外观、导航、搜索展示字段，随后重验；不存鉴权、公开数据、资料或凭据。上限 **24 小时、512 Ki UTF-16 字符**，损坏/超限/存储失败回正常网络；退出/切账号/撤权清理，局部拒绝剔除对应数据。未重验导航可打开，但编辑/排序/搜索保存禁用；直接进设置不恢复，从首页进设置也移除未验证内存，防止整对象自动保存覆盖新配置。验证状态独立订阅，不能靠业务数据引用变化。
- 鉴权、站点、外观、导航、模块配置 API 读取预算 **15 秒**，含响应体；超时中断并给本地化重试，主动取消另论。上传/写入不自动套期限或重试，客户端取消不保证服务端回滚。
- 构建生成文本 `.gz/.br`，Go 在原 URL 协商；无派生仍读原文。哈希 assets 长期 immutable，HTML/worker/无哈希入口重验，API/上传不套用；sidecar 不公开、不进 precache。

## 组件与主题约定

`Providers.tsx` 管基础 token/portal 样式，`styles.css` 管主题变量，`Section` 统一设置分区/状态/动作区。用 Ant Design 公开 token/属性，不依赖内部 DOM；装饰图标不参与无障碍名称，功能控件可读。布局、材质、字色与壁纸只在 [UI](ui-design.zh-CN.md)维护。

版本源/构建校验见 [07](../handbook/07-environment.md#前端环境变量)；关于/配置导出使用发布版本，不用构建日期，tag 前缀 `v`。

## 页面文案

用准确功能名、动作和结果，说明保存范围/后果/恢复；不加口号、装饰英文或未经确认定位。站点标题/副标题/页脚按管理员配置。关闭本地应用搜索时只提示网页搜索；详情卡无描述时不拿地址充当描述。

## 数据与会话

TanStack Query 管服务端状态/轮询，Zustand 持久化主题/语言/内外网偏好和会话；切账号创建新 QueryClient，取消旧查询、清缓存。请求带 `token/lang` 和取消信号；HTTP 成功仍检查业务 `code`，仅 `1202` 缺配置可用默认，数据库错误保持可见。角色/公开模式入口来自 `getAuthInfo`，最终权限由服务端判定。

`QueryError` 首次失败替换内容，刷新失败保留本会话数据并标过期，局部失败保留其余内容；鉴权拒绝隐藏缓存/操作，包括挂载点、公开账号、Docker 指标/日志等子查询。摘要/重试本地化，原文仅管理员按需展开。`getNavigation` 一次取分组/应用；外观损坏仅回落提示，调整保存或明确修复才写回，路由异常提供恢复/安全模式。

自动保存取消旧读并更新缓存，不逐次重取；站点手动保存先更新再重取，失败不能恢复旧值。默认搜索引擎按名称/URL/图标完整匹配，旧值才回退 URL，同 URL 不同引擎仍可选。仅改头像兼容历史非空昵称，改名按 3–15 字符。

## 功能与边界

- 普通应用点击遵循网络模式、缺失地址回退及存量打开方式；原生中键/修饰键保持。排序用手柄/空格/方向键，期间禁打开/编辑/应用菜单，结束恢复。项目/分组校验、删除迁移及权限见 [06](../handbook/06-api-design.md#导航配置与导入)。
- 应用菜单无图标覆盖按钮；右键、菜单键、Shift＋F10 打开，箭头导航、Esc/Tab 退出；编辑跨组仍按稳定 ID 回焦。外点、滚动、窗口变化、应用过滤、离页/切账号关闭。Shift＋右键/空白处保留浏览器菜单，触屏仅接收 contextmenu，不加长按计时器；iOS 缺口见 01。
- 菜单“主地址”严格对应表单“地址”，独立于当前网络模式；未填不显示，首尾去空白后完全相同才合并，不做 URL 归一化/写回。主操作用存量打开方式，快捷新标签/iframe只影响本次；访客可打开/复制，管理权限及删除确认保留。复制相对地址解析完整网址，仅写成功才提示，失败给已选地址手抄，迟到结果不弹窗。iframe保留限制说明/外部入口，不凭 load 判成功，不放宽 sandbox。
- `ItemTitle` 仅名称实际溢出时提示，不给图标/链接网址 title；改名、尺寸、字体加载后重测，隐藏名称无提示入口，完整可访问名称仍保留。
- 图库懒加载 `thumbnailSrc`，失败回原图；预览/壁纸/引用始终用原 `src`。首页仅普通同源 `/uploads/` PNG/JPEG 派生，其他格式/WebP/外链/查询或片段保留原 URL；失败依次原图→文字，换图重置。保存/编辑不改 URL，壁纸不用 320px 派生。服务端限制及 WebP 禁解码见 [06](../handbook/06-api-design.md#缩略图)。
- 上传格式预检、单文件 **10 MiB**，逐文件状态/重试；上传成功后刷新失败不重复上传。单图新选与旧失败重试互斥，多图可并发。上传时外观/资料暂停自动保存、实体禁提交；保存时禁新上传，但外观/资料可继续编辑。每次 `ImageUpload.onStart` 捕获独立处理器，按字段草稿版本回填，A→B→A 仍废弃旧结果；favicon另核对URL/类型。
- 导入仅设置入口，连续选文件只取最新，确认时冻结文件/选项；显示新增/覆盖数量，覆盖所需当前数据失败时禁用并可重试，稳定 `requestId` 重试同请求。引用替换可跨个人/公共图库翻页，只改授权引用、保留原图。独立图库上传只建文件，壁纸上传随后自动保存；导出范围见 [13](../handbook/13-operation-guide.md)。
- 模糊/暗度 **0–10** 档映射内部 **0–30/0–1**，读或改别字段不量化旧值。滑块/最大宽度及单位/页脚/验证码均有可访问名称，排序播报用本地化名称/位置。
- 可见页监控 **5 秒**轮询；访客须公开账号同时开启监控/访客显示。Docker动作与私网favicon权限见06/07。关于禁裸链接自动识别、最多 **32768 字符**，显式Markdown链接可用。

## 重构范围

旧 Vue/Pinia/Naive UI 已移除，不并行维护或迁移旧浏览器状态；Go接口/部署产物保留。

## 页面入口与编辑约定

入口/权限见 [13](../handbook/13-operation-guide.md)，未知设置404、越权403。非公开登录不显示返回受保护首页；从公开首页登录才有返回，登录前可切语言。

外观/搜索/监控/资料停改 **600ms** 校验并自动保存，滑块拖动/上传暂停；按表单串行、保留保存后新草稿。同页多分区须全部完成才报已保存，局部成功不得覆盖失败/等待/无效/未保存状态；放弃离页清该页持久错误。失败留输入可重试，不无限重发。内部导航等待正常保存，失败/无效/上传/密码草稿才询问放弃；刷新/关闭用原生保护。实体Esc/遮罩/取消均保护草稿，短窗口动作可达。恢复默认确认后自动保存；站点/密码/实体及数据操作仍明确提交。

主题/语言/网络模式本机即时生效；登录用户首页选搜索引擎会保存，失败回滚可重试，访客只本页。切账号保护资料/密码草稿；新密码 **6–72 UTF-8 字节**、登录上限72。

## HTTP 与自定义代码

局域网HTTP可登录/编辑/导入，ID用 `crypto.getRandomValues`，不依赖安全上下文的 `randomUUID`。`useSessionRequest` 绑定页面/发起会话（含匿名登录），卸载取消请求/确认框；响应及JSON完成再验会话/取消，旧回调不得登录/导航，保留调用方取消。

页脚经DOMPurify；CSS随内容更新，同JS不因标题/主题/重取重复执行。新JS不能撤销旧监听/定时器，彻底替换须刷新。`/?safeMode=1#/settings/site` 或 `/#/settings/site?safeMode=1` 跳过CSS/JS；本页曾执行脚本则重载清副作用。仅用数据库自定义配置，不默认加载 `/custom/index.css`、`/custom/index.js`。

## 可选 PWA

`VITE_GLOB_APP_PWA=true` 构建，默认关闭。Go仅显式提供清单/注册/worker/图标及 `/index.html`、`/static/global.css`，不开放目录，运行库内联。安装需HTTPS（localhost除外），局域网HTTP仍可访问；仅缓存静态壳，快照须在线新鉴权，无离线业务/写入承诺。执行结果与平台缺口见 [01](../handbook/01-current-status.md)。
