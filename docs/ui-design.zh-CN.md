# ZPanel 视觉设计规范

本规范用于 React + Ant Design 前端。目标是让 ZPanel 呈现轻盈、有呼吸感的个人桌面：背景提供空间深度，少量承载内容的表面使用磨砂玻璃，操作始终清楚易读。

## 视觉原则

1. **先布局，后材质。**首页采用紧凑的壁纸桌面布局：桌面名称与时钟在左，搜索框在右，与下方应用分组保持左沿对齐；窄屏改为上下排列。应用图标直接按分组排列，所有尺寸的工具条统一悬浮在右下。标题、分组和图标下文字不加底板。玻璃主要用于搜索框和图标底座，不把首页做成业务卡片列表。
2. **表面数量要少。**同一区域只保留一层主要容器。设置页使用一个悬浮玻璃窗口，导航融入窗口侧栏，表单分区用间距与细分隔线区分，不再把每组字段放进独立的实色大卡片。
3. **区分两种应用样式。**详情样式是横向的玻璃导航卡；小图标样式只有图标底座使用玻璃，文字在底座之外。两种样式共用内容和交互，但不共用整张卡片的外观。
4. **透明度必须服务可读性。**首页默认固定白字，提供手选黑字及自定义色，配细描边和轻阴影；有无壁纸时均不自动换字色。整图亮度由手动暗度及显式开启的「自动调整壁纸对比度」控制，不给每组文字加深色大板。设置窗口仍跟随浅/深主题；保留图标独立底色与内部配色。
5. **动效保持克制。**应用图标与详情卡悬停只加深阴影，位置与大小保持稳定；系统要求减少动态效果时禁用动画和过渡。交互状态仍须能通过阴影和焦点轮廓辨认。

## 页面层级

| 页面 | 背景 | 主要表面 | 内容组织 |
|---|---|---|---|
| 首页 | 多层低对比渐变或用户壁纸 | 搜索框、监控卡、详情导航卡、悬浮工具栏 | 桌面左侧名称与时钟、右侧搜索；窄屏上下排列；应用按用户分组排列 |
| 小图标首页 | 同首页 | 仅图标底座 | 标题在图标下方，避免出现一排排矩形业务卡 |
| 设置页 | 已保存的用户壁纸或柔和渐变，统一模糊并叠加主题遮罩 | 一体化悬浮玻璃窗口、独立底部状态/操作区 | 侧栏与内容同窗；内容独立滚动；分区使用留白与细分隔线 |
| 登录页 | 柔和渐变 | 登录表单 | 与首页共用玻璃材质，不堆叠装饰卡片 |

## 实现约定

- 项目标识统一为蓝紫色（`#5266eb`）圆角底配白色 Z；`src/assets/logo.svg` 是唯一图标源，登录页和设置导航共用 `BrandMark` 组件，favicon、ICO、Logo PNG、默认头像、Apple Touch 与 PWA 图片同步派生，PWA 主题色沿用同一蓝紫色。网页默认 favicon 使用构建指纹地址，历史默认站点图标路径归一到此资源，自定义站点图标仍优先生效。
- `src/app/styles.css` 中的 `--glass`、`--glass-raised`、`--glass-line` 和阴影变量定义材质。浅色与深色各有一组；自定义壁纸在 `.has-wallpaper` 中覆盖。新增业务表面应优先复用这些变量。
- 菜单、弹窗、下拉、提示和通知统一使用根主题的 `--glass-popup` 系列变量，供 portal 浮层共享厚磨砂底色、正文色、低对比边缘和阴影；不继承首页壁纸字色。Ant Design 通过公开语义样式设置材质，正文输入保留清晰底色。弹窗居中且限制在视口内，长内容独立滚动，标题与操作区始终可见。
- 添加/编辑项目弹窗宽 820px，基础字段两列，图标类型、内容和背景色集中为三列，图片上传操作紧随图标内容；字段间距通过局部 Form token 收紧，字号与控件高度保持。常见桌面视口初始表单应完整呈现，640px 及以下转单列；窄屏、短窗口、错误或上传记录增加高度时，仅内容区滚动，标题与操作区保持可见。
- 降低透明度或提高对比度偏好下使用更实的表面；不支持背景模糊时，设置窗口和浮层回退为不透明主题底色。减少动态效果的既有规则继续生效。
- 面板配置保留已有字段与数值：上下边距以页面宽度百分比为基础，顶部另按同一数值的 0.8 倍视口高度百分比限制，在宽而矮的窗口自动收紧；0 仍为 0，较大的设置仍成比例增加顶部留白。使用稳定视口高度 `svh`，不支持时回落到原宽度百分比；底部继续按原宽度百分比计算，左右边距为像素。默认小图标样式，图标底座为 70px。详情卡横排，单个项目约 76px 高。设置页显示单位并说明顶部的自适应行为。
- 应用图片占满底座的图片区，使用 `contain` 保持比例，不统一缩小或裁切标志；完整方图贴合圆角，非方图及透明部分露出底座。底座圆角为尺寸的 24%，以轻阴影表现层次，不画亮色轮廓。小图标保留 70px，详情样式保留桌面 50px、窄屏 44px；图片自身的留白与白色像素不自动删除。
- 新增项目的图标背景默认留空，使用随主题/壁纸变化的轻磨砂；已有显式背景色继续生效。编辑器的背景输入可清空恢复磨砂，并以同一图标组件提供实时预览；输入图片地址、文字或底色时不必保存即可查看，失败图片更换地址后重新加载。预览不写回配置，也不自动改写历史白色底座。
- 图标磨砂使用独立的 `--icon-surface` 与 `--icon-blur`，浅深背景均以低透明度中性色透出背后的图案，不叠加浓黑底；编辑图标及壁纸预览使用同一材质。文字、单色图标与图片失败回退增加薄保护层保证可读，显式背景色不叠该层。降低透明度、高对比及强制颜色偏好下使用相应实底并取消模糊。图片里已包含的白色或深色底不由 CSS 自动删除。
- 首页名称使用 1.15 行高、桌面最大 40px，字重 750；时钟和应用名称 650，日期、描述与页脚 500，分组 750。字号与图标尺寸保持。宽度至少 1024px 时页头采用可换行的左右布局，身份区与搜索的基础宽度分别为 280px、420px，列间距 48px；用户配置较窄内容宽度时自然堆叠。窄屏为上下左对齐，行间距 20px，手机为 16px。搜索最小高度 52px，关闭搜索后身份区自然占满，不保留空列。
- 页头到后续内容留白为 32px，分组上间距为 28px，分组标题下间距为 16px；空分组上间距 24px、标题下间距 4px，避免空内容形成大段空白。相邻块级外边距按 CSS 折叠规则取大值，不累加；手机及宽度大于 640px、高度不超过 600px 的窗口，页头下留白与常规分组上间距均为 24px。监控、首次编辑提示、错误与空状态仍按正常文档流占位，搜索错误独占页头下一行，不用定位或负外边距强拉链接区。
- 页头与应用分组共用左沿及完整配置宽度。所有尺寸的设置/登录与内外网入口统一为右下水平工具条，距右/下 18px 并叠加安全区，按钮 44px、间隙 4px、内边距 5px；搜索保持独立完整一行或页头右列，不为工具条缩宽。向下滚动超过 320px 后，在工具条最左显示同尺寸的回顶按钮，以细线分隔；右端原按钮位置不变，不动画移动工具条。回滚到 240px 以内才隐藏，避免阈值附近闪烁。点击回顶后焦点回到页首名称，减少动态效果时即时滚动；手动滚动导致已聚焦回顶按钮隐藏时，仅把焦点交还原工具按钮。页脚底部预留 92px 加安全区，末行应用和长页脚滚至末尾后可完整查看；窄矮、零边距、无搜索及单按钮仍须可点、可键盘进入。
- Ant Design 继续负责按钮、输入框、菜单、表单、弹窗和反馈。`src/app/Providers.tsx` 统一基础 token 与共享浮层的语义样式，材质取自根主题变量；业务页面的材质与布局由页面 CSS 决定。
- 首页搜索栏由外层容器统一显示聚焦边框与光晕；内部输入框和搜索引擎选择框通过公开的 `styles.root` 关闭重复轮廓，鼠标和键盘操作均保留外层焦点提示。
- 保留用户已配置的壁纸、尺寸、上下边距、图标样式及自定义 CSS。自定义 CSS 可覆盖本规范的样式；遇到特殊壁纸时应优先检查文字对比和用户自定义覆盖。
- 首页文字默认固定白色，设置提供白色/黑色和高级自定义色；空值、缺键及旧默认 `#1f2937` 只在显示时解析为白色，不在读取时写回。选择不随壁纸、裁切或界面主题改变；图片失败或无壁纸仍保留人工字色。
- 登录页是未开放访客模式时的唯一入口，不显示指向受保护首页的返回按钮。只有从公开首页进入登录页时才显示“返回首页”；设置页保留一个明确的返回入口。登录前可切换界面语言，顶部工具参与正常文档流，窄屏或长语言名称换行后仍与表单分开。副标题配色分别适配浅深主题。
- 文案必须与当前设置一致：关闭本地应用搜索时，搜索框只提示网页搜索；没有描述的详情卡不以地址充当描述。排序期间应用点击不触发编辑或跳转。
- 应用图标悬停不显示网址或名称提示；只有下方名称实际省略时，悬停名称文字才显示完整名称，完整可见的名称不弹提示。两种布局采用同一规则，提示复用共享磨砂样式，窗口或文字尺寸变化后重新判断。
- 浏览器验收至少查看桌面与手机宽度、浅色与深色主题、默认背景与自定义壁纸、小图标与详情卡片。功能回归仍按 `docs/frontend.zh-CN.md` 执行。

## 首页配色与壁纸

- 用户 2026-10-22 提供的参考图是首页当前视觉方向：壁纸是主视觉，标题与时钟直接展示，图标独立排列，分组靠留白区分；不使用整组卡片、标题胶囊或页脚底板。设置页的玻璃窗口不复用于首页。
- 文字与壁纸处理分开：人工颜色通过既有 `iconTextColor` 保存，名称、默认时钟、分组、应用名称/描述、空提示及页脚统一生效。默认白字使用 0.4px 细黑描边、填充优先绘制和轻阴影，黑字使用细浅描边；不再根据壁纸给黑字加白色光晕。显式时钟/监控颜色仍优先。描边只落在透明文字叶节点，搜索、工具、监控和弹窗维持各自清楚的控件表面。
- 「自动调整壁纸对比度」缺省关闭，开关只处理整图遮罩，不能改变人工字色。开启后按可见 CSS 像素、实际 fixed 区域及 cover 裁切，先合成图片与主题底色，再应用相同扩边和模糊，最后结合暗度计算所需遮罩；固定黑白及自定义色按实际 RGBA 求解，无法达到目标时不降低原有最差对比。继承、系统色、currentColor、上下文表达式（含 CSS 转义）或 Canvas 不接受的值继续保留原 CSS，但视为无法分析，不额外加罩。普通模式最多 256 像素长边采样，不额外加罩；跨域、超大画布或不支持 Canvas 模糊时，黑白模式保守回退，自定义色无法取样时保留原图与人工字色。采样只在浏览器进行，不上传像素或把分析结果写回。
- 加载中保持原图初态；区分可展示但不可分析与实际失败，失败不清空地址。过时分析结果不得覆盖新选择；预览图层即时变化，分析延迟合并、说明区按所有状态最大高度占位。普通模式的描边阴影不能保证任意细纹理均达到 4.5:1，可手调暗度或开启遮罩；任意自定义色及透明文字本身可能达不到目标，不替用户换色。
- 搜索、工具栏、监控、详情卡和错误状态按人工黑白的中性 palette 提供独立表面，图标材质与内部字标沿根主题及其显式底色，不能因首页黑白选择改变。图片和多色标志保留原色。更多对比或强制颜色偏好采用成对 Canvas/CanvasText 实底、隐藏壁纸图层、关闭文字描边阴影及图标模糊；这是系统辅助偏好的显式覆盖。
- 有壁纸时，标题和分组保持透明，图标保留原图颜色和用户背景色，仅底座使用轻玻璃。空分组的提示与添加收为低干扰的一行，配置导入只保留设置中的入口；桌面编辑工具悬停或键盘聚焦时显示，触屏保留可见入口。首次访问展示简短的编辑提示并显露工具；用户关闭后仅在当前浏览器记住，访客不显示编辑提示或编辑入口。明确的错误状态可使用紧凑玻璃表面。
- 小图标与详情卡共用配色，次要说明保持可读，禁用按钮与正常操作清楚区分；不以降低整个内容区域透明度来淡化信息。无壁纸时也保留手选文字色，控件表面与之配套；设置窗口仍沿界面主题。
- 默认无额外调色、异常状态及预览/配置回归见 `tests/e2e/wallpaper-rendering.spec.ts`；自动模式的文字对比及既有入口回归见 `tests/e2e/home-appearance.spec.ts`：亮/暗/混合壁纸、最不利底色下的文字对比度、320/390px 手机、UI 主题与壁纸明暗相反、窗口裁切变化、细密黑白纹理、图标底色对比、跨域回退、显式标题/描述色、首次提示及键盘/触屏入口。

应用菜单采用紧凑操作面板：每组用带图标的「打开主地址」或「打开内网地址」作为主操作，下方三个轮廓快捷项同时显示图标与「新标签页／内嵌／复制」短标签；编辑、删除置于分隔线下，删除保留危险色。主地址对应表单中的「地址」，不表示当前网络模式下的默认打开目标；主/内网地址去除首尾空白后完全相同时仅展示一组操作。桌面宽 272px、主行 34px、快捷项 32px，外层圆角 14px，触屏主行 40px、快捷项 44px。快捷项保留含地址分区的完整可访问名称。菜单复用浅/深主题磨砂材质、中性悬停底色和内收焦点轮廓，不继承壁纸文字色。图标上不显示菜单按钮；右键按指针定位，聚焦应用后可用菜单键或 Shift＋F10 打开。触屏接收浏览器长按产生的菜单事件；iOS 纯触屏入口缺失仍为已知待修复项。菜单收进视口边界，窄屏/低高度允许内部滚动。

## 设置窗口

- 桌面窗口最大宽 1280px、高为视口的 90%（最大 900px），圆角 24px；侧栏宽 222px，内容内边距 32px。标题约 23px，减少后台大标题感。
- 只有窗口使用主要玻璃材质，不再分别堆叠侧栏卡片和内容卡片。输入控件保留较实的主题表面，确保壁纸上的可读性。
- 设置窗口以半透明磨砂表面和分层外阴影表现悬浮厚度，不使用亮白描边；侧栏、菜单和顶部不画硬分隔线。分组行使用轻薄透光底色和柔和投影，编辑、删除及居中拖动手柄融入行内，键盘焦点仍须清楚可见。浅深主题分别配置材质，相关变量只作用于设置页。
- 内容区独立滚动，标题与导航保留；切换设置分类后内容回到顶部。风格设置的自动保存状态及恢复默认动作、站点设置的手动保存栏位于滚动区域之外，独立占据窗口底部空间，不遮挡字段及键盘焦点。其他页面使用统一样式的表单操作区；搜索、监控与个人资料分别自动保存，密码保持明确提交。状态始终占位，日常编辑不反复增删草稿提示。
- 风格设置提供浅色、深色、跟随系统的视觉选项；标识和壁纸预览随字段草稿更新，壁纸预览与首页共用图层、人工字色和遮罩计算，按当前窗口比例缩小并等比换算模糊及扩边；草稿中的暗度、自动对比度和应用文字色实时呈现；参数分析延迟 160ms 合并，同图保留现有配色和状态，说明区域保留高度以免挤动滑块；示例内容不代表首页布局。预览显示加载/失败及无法分析时的简短说明。长名称省略显示并保留完整标题提示，标识图片失败时回退到名称首字符，更换地址后重新加载。主题选项随内容区宽度收缩，中文与英文在窄窗口均保持可操作；窗口背景仍使用已保存壁纸。
- 开关行采用左侧标签、右侧开关，在 320px 下也保持同行并允许标签换行。复杂表单保留双列，手机使用单列；手机隐藏侧栏，以分类选择器导航，窗口保留 8px 外边距。窗口标题和正文同名分区不重复显示；空图库提供明确上传引导并隐藏无意义的分页，手机账号表固定操作列。
- 外观、搜索与监控及资料表单显示自动保存状态，成功气泡合并、失败保留输入并显示重试，字段无效时提示修正。搜索与监控同页反馈汇总全部分区，任何失败保持错误，其他分区成功不能覆盖；仍有草稿时不显示全部已保存。密码和站点保留未保存提示与提交；普通内部离页先等待自动保存，失败、无效、上传和密码草稿继续保护。监控颜色属于低频选项，默认收进可用键盘展开的高级配色区，色块辅助预览，输入仍支持完整 CSS 色值。
- 主题即时保存到当前浏览器；外观、搜索与监控及资料停改 600ms 后自动保存，滑块松手后保存，上传期间暂停；写入时允许继续编辑并串行提交最新草稿。壁纸模糊和暗度统一为 0–10 整数档，内部单位及已有数值保留。站点代码/安全设置、密码、实体编辑、导入覆盖、删除和恢复默认等保留明确动作，恢复默认确认后自动保存。
- 设置项涉及访客可见范围、跨账号共享、覆盖数据或即时生效时，在所属分区显示简短说明；只在具体字段有独立含义时补字段备注。说明与现有标题、表单同层呈现，不另加提示卡片。
- 读取失败使用共享状态区，与页面同一表面：一句可理解的结果、简短处理建议和重试操作；仅管理员排障场景按需展开技术详情。首次读取失败时替换表格或列表，不能同时出现“暂无数据”；已有数据刷新失败或局部数据失败时保留可用内容，用紧凑状态区说明受影响部分。空数据只表示请求成功且结果为空。
- Docker 排障状态局部使用紧凑左对齐的轻玻璃提示，图标、说明与重试保持同一行，手机动作换行；技术详情默认折叠，展开后限制高度并允许长路径换行。容器列表、资源、日志及鉴权错误共用此局部样式，不改变其他页面的共享状态布局。
