# ZPanel 视觉设计规范

本规范用于 React + Ant Design 前端。目标是让 ZPanel 呈现轻盈、有呼吸感的个人桌面：背景提供空间深度，少量承载内容的表面使用磨砂玻璃，操作始终清楚易读。

## 视觉原则

1. **先布局，后材质。**首页沿用 Vue 版的空间位置：中部名称与时钟并排，搜索框在下方，监控和分组继续向下排列，常用工具悬浮在右下。玻璃效果用于强调层级，不能靠增加模糊掩盖拥挤的布局。
2. **表面数量要少。**同一区域只保留一层主要容器。设置页使用一个悬浮玻璃窗口，导航融入窗口侧栏，表单分区用间距与细分隔线区分，不再把每组字段放进独立的实色大卡片。
3. **区分两种应用样式。**详情样式是横向的玻璃导航卡；小图标样式只有图标底座使用玻璃，文字在底座之外。两种样式共用内容和交互，但不共用整张卡片的外观。
4. **透明度必须服务可读性。**浅色主题使用亮玻璃，深色主题使用深玻璃。首页自定义壁纸上使用深色半透明表面与浅色文字；设置窗口始终跟随浅/深主题，以主题遮罩及较实的控件表面保证可读性；壁纸、主题和用户指定的图标背景色仍可使用。
5. **动效保持克制。**悬停只做轻微上移和阴影变化；系统要求减少动态效果时禁用动画和过渡。交互状态仍须能通过边框、颜色和焦点轮廓辨认。

## 页面层级

| 页面 | 背景 | 主要表面 | 内容组织 |
|---|---|---|---|
| 首页 | 多层低对比渐变或用户壁纸 | 搜索框、监控卡、详情导航卡、右下工具栏 | 名称与时钟并排；搜索在下；应用按用户分组排列 |
| 小图标首页 | 同首页 | 仅图标底座 | 标题在图标下方，避免出现一排排矩形业务卡 |
| 设置页 | 已保存的用户壁纸或柔和渐变，统一模糊并叠加主题遮罩 | 一体化悬浮玻璃窗口、轻薄固定底部保存栏 | 侧栏与内容同窗；内容独立滚动；分区使用留白与细分隔线 |
| 登录页 | 柔和渐变 | 登录表单 | 与首页共用玻璃材质，不堆叠装饰卡片 |

## 实现约定

- `src/app/styles.css` 中的 `--glass`、`--glass-raised`、`--glass-line` 和阴影变量定义材质。浅色与深色各有一组；自定义壁纸在 `.has-wallpaper` 中覆盖。新增业务表面应优先复用这些变量。
- 面板配置沿用旧版含义：上下边距为相对页面宽度的百分比，左右边距为像素；默认小图标样式，图标底座为 70px。详情卡横排，单个项目约 76px 高。设置页控件须显示单位。
- Ant Design 继续负责按钮、输入框、菜单、表单、弹窗和反馈。`src/app/Providers.tsx` 只配置全局基础 token；业务页面的材质与布局由页面 CSS 决定。
- 保留用户已配置的壁纸、尺寸、上下边距、图标样式及自定义 CSS。自定义 CSS 可覆盖本规范的样式；遇到特殊壁纸时应优先检查文字对比和用户自定义覆盖。
- Vue 旧默认导航文字色 `#1f2937` 视为“跟随主题”，避免在深色主题或壁纸上出现低对比文字；其他自定义颜色仍按用户配置显示。
- 登录页是未开放访客模式时的唯一入口，不显示指向受保护首页的返回按钮。只有从公开首页进入登录页时才显示“返回首页”；设置页保留一个明确的返回入口。登录前可切换界面语言。
- 文案必须与当前设置一致：关闭本地应用搜索时，搜索框只提示网页搜索；没有描述的详情卡不以地址充当描述。排序期间应用点击不触发编辑或跳转。
- 浏览器验收至少查看桌面与手机宽度、浅色与深色主题、默认背景与自定义壁纸、小图标与详情卡片。功能回归仍按 `docs/frontend.zh-CN.md` 执行。

## 设置窗口

- 桌面窗口最大宽 1280px、高为视口的 90%（最大 900px），圆角 24px；侧栏宽 222px，内容内边距 32px。标题约 23px，减少后台大标题感。
- 只有窗口使用主要玻璃材质，不再分别堆叠侧栏卡片和内容卡片。输入控件保留较实的主题表面，确保壁纸上的可读性。
- 内容区独立滚动，标题与导航保留；切换设置分类后内容回到顶部。风格与站点设置的保存栏位于滚动区域之外，独立占据窗口底部空间；草稿提醒换行时压缩上方可视区，不遮挡字段及键盘焦点。其他页面使用统一样式的表单操作区，搜索与监控、个人资料与密码仍分别提交。未保存提醒及离页确认沿用既有行为。
- 风格设置提供浅色、深色、跟随系统的视觉选项；标识和壁纸预览随字段草稿更新；长名称省略显示并保留完整标题提示，标识图片失败时回退到名称首字符，更换地址后重新加载。主题选项随内容区宽度收缩，中文与英文在窄窗口均保持可操作。窗口背景使用已保存壁纸，壁纸预览仅展示图片，不承诺完整首页或模糊参数的实时预览。
- 开关行采用左侧标签、右侧开关。复杂表单保留双列，手机使用单列；手机隐藏侧栏，以分类选择器导航，窗口保留 8px 外边距。
- 主题即时保存到当前浏览器；其他面板设置仍需点击保存。布局调整不改变权限、配置字段或存储语义。
- 设置项涉及访客可见范围、跨账号共享、覆盖数据或即时生效时，在所属分区显示简短说明；只在具体字段有独立含义时补字段备注。说明与现有标题、表单同层呈现，不另加提示卡片。
- 读取失败使用共享状态区，与页面同一表面：一句可理解的结果、简短处理建议和重试操作；仅管理员排障场景按需展开技术详情。首次读取失败时替换表格或列表，不能同时出现“暂无数据”；已有数据刷新失败或局部数据失败时保留可用内容，用紧凑状态区说明受影响部分。空数据只表示请求成功且结果为空。
