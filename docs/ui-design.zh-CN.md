# ZPanel 视觉设计规范

React/Ant Design的视觉参数正文；交互与保存见 [前端开发](frontend.zh-CN.md)，原因见 [11](../handbook/11-decisions.md)，验收见 [回归入口](frontend-audit.zh-CN.md)。

## 视觉原则

首页以壁纸、透明标题/分组和独立图标组成个人桌面，不加整组卡片、标题胶囊或页脚底板；玻璃用于搜索、监控、图标底座/详情卡和浮层。设置使用一体悬浮窗口，不复用于首页。小图标文字在底座外，详情卡横排；二者共享行为、不共享整卡外观。悬停只加深阴影，不位移/缩放，焦点始终可辨。

## 页面层级

| 页面 | 表面与组织 |
| --- | --- |
| 首页 | 渐变或用户壁纸；名称/时钟左、搜索右，窄屏上下左对齐；分组靠留白区分，工具统一右下 |
| 设置 | 已保存壁纸/渐变加模糊及主题遮罩；同窗侧栏/内容、独立底部状态与动作区 |
| 登录 | 渐变与玻璃表单；语言工具在文档流，长名称换行不挤表单，副标题适配浅深 |

## 实现约定

- 蓝紫 `#5266eb` 圆角底/白Z；`src/assets/logo.svg` 唯一源，`BrandMark` 共用，favicon/ICO/Logo PNG/默认头像/Apple Touch/PWA派生；PWA同主题色，默认favicon带构建指纹、旧默认路径归一，自定义优先。
- `styles.css` 的 `--glass/--glass-raised/--glass-line` 及阴影定义浅深材质，`.has-wallpaper` 覆盖；portal用根 `--glass-popup` 系列，不继承首页字色。`Providers.tsx` 通过公开token/语义样式统一控件，业务CSS管布局，输入保留较实底色；弹窗居中限于视口，长内容独立滚动，标题/动作保留。
- 低透明/高对比用实表面，无背景模糊则窗口/浮层回退不透明主题底；强制颜色/更多对比用成对Canvas/CanvasText、隐藏壁纸、取消描边阴影与图标模糊。自定义CSS可覆盖，异常先查覆盖与壁纸。
- 减少动态效果时全局 `transition-duration:0s`；关键帧及loading图标限定width/opacity/margin保留极短结束过渡，不能给定位属性例外。详见11的测量根因。

搜索焦点由外层统一显示边框/光晕，内部输入与选择器用公开 `styles.root` 关闭重复轮廓，鼠标/键盘均保留外层提示；实现见 `Home.tsx` 的 `.search-box` 与 `styles.css` 的 `.search-box:focus-within`。

### 首页几何

| 对象 | 参数与兼容 |
| --- | --- |
| 配置边距 | 上下沿页面宽度百分比；顶部再取同数值×0.8的视口高度百分比上限，使用 `svh`，不支持则回原宽度百分比。底部不变，左右为px；保留原值/0语义，大值仍同比增加留白，设置标单位/自适应说明 |
| 页头 | 宽≥1024px可换行左右布局，身份/搜索基础宽280/420px、列间48px；配置窄则自然堆叠。窄屏行间20px、手机16px；搜索最小高52px，关闭不留空列；与分组共左沿/完整配置宽度，不为右下工具条缩窄搜索 |
| 字体 | 名称行高1.15、桌面最大40px、字重750；时钟/应用名650，日期/描述/页脚500，分组750；其他字号/图标尺寸保持 |
| 留白 | 页头后32px、分组上28px/标题下16px，空组24/4px；相邻margin折叠取大值。手机或宽>640且高≤600px时，页头后/分组上均24px |
| 工具与回顶 | 右/下18px加安全区，按钮44px、隙4px、内边5px。滚动>320px在左侧加回顶，≤240px隐藏，原按钮不动；点击回焦页首名称，减少动态效果即时滚动，手滚使聚焦按钮隐藏才交还原工具。页脚底部预留92px加安全区，末行/长页脚可完整滚入；零边距、无搜索、窄矮、单入口仍可命中/键盘进入 |
| 图标 | 默认小图标70px；详情底座桌面50/窄屏44px，横卡约76px高；圆角为尺寸24%。图片 `contain` 占满图片区，方图贴角，非方/透明露底；不自动删图片白边/留白、不裁标志、不统一缩小 |

公共壳复用默认布局，通用标题/真实时钟/静态占位，无扫光；仅阶段说明播报，失败留在文档流、时钟持续。排序/监控失败即使无壁纸也有玻璃承载，避免浅字落浅底。私有读取/回焦顺序见[加载契约](frontend.zh-CN.md#加载边界)。监控/提示/空错态均占文档流，搜索错误独占页头下一行，不用定位/负margin拉导航。

图标独立 `--icon-surface/--icon-blur` 为低透明中性轻玻璃，不叠浓黑/亮轮廓；文字/单色/失败回退加薄保护，显式背景不加。新空背景用玻璃、旧显式色保留，编辑清空恢复；实时预览共用组件，不写回，换地址后重试。悬停图标无提示，仅实际省略名称提示全文，尺寸/字体变化重测。空组一行提示/添加，导入仅设置；编辑工具桌面悬停/聚焦、触屏可见，首次提示显露工具，关闭仅记当前浏览器，访客无编辑入口。

## 首页配色与壁纸

- `iconTextColor` 固定人工白/黑/自定义；空/缺键/旧默认 `#1f2937` 仅显示为白，读取不写回，主题/裁切/失败/无图均不换色。作用于名称、默认时钟、分组、应用名/描述、空提示/页脚；显式时钟/监控色优先，图标内部独立。白字0.4px黑描边、填充优先加轻阴影，黑字细浅描边，不加白光晕；仅透明文字叶节点描边。
- `wallpaperAutoContrast` 缺省关闭，普通模式最多256px长边采样、不加额外整图遮罩；暗度/模糊仍按用户值。开启只求遮罩、不换字色：按可见CSS像素、实际fixed区域/cover裁切，合成主题底、相同扩边/模糊再算暗度。固定色用真实RGBA，不可达不恶化原最差对比；继承/系统/currentColor/上下文表达式（含转义）及Canvas不接受的值保留CSS、不加罩。
- 自动对比开启且图片/人工文字语义未变时，视口或主题重分析保留已显示遮罩，等新结果一起接管；换图、改字色或关闭自动对比立即按新语义处理，不沿用旧罩。
- 跨域/超大画布/不支持Canvas滤镜时，黑白保守回退，自定义色保留原图/字色；区分可显示但不可分析与加载失败，失败不清URL，迟到分析不覆盖新选择。像素不上传，结果不写回。普通描边不保证任意细纹理4.5:1，自定义/透明色也可能不可达，用户可调暗度或开遮罩。
- 搜索/工具/监控/详情/错误用人工黑白的中性palette及独立表面；图标材质沿根主题/显式底色，多色图片保持。无图也保留人工字色，设置仍跟主题；不降低整区opacity淡化信息。

## 应用菜单

每地址分区：图标主操作，下方三列轮廓快捷项“新标签页/内嵌/复制”；管理项在分隔线下、删除危险色。桌面宽272px、主行34px、快捷32px、圆角14px；触屏40/44px。完整名称含地址分区，浅深磨砂/中性hover/内收焦点、不继承壁纸字色，窄矮可内部滚动并避让视口。地址、原生链接、键盘/触屏权限见[功能契约](frontend.zh-CN.md#功能与边界)。

## 设置窗口

| 对象 | 布局 |
| --- | --- |
| 主窗口 | 桌面最大1280px、视口90%且≤900px高、圆角24px；侧栏222px、内容padding32px、标题约23px。手机8px外边距，分类选择器替代侧栏 |
| 层级 | 单层玻璃、分层外阴影，无亮白描边/侧栏菜单硬线；分区靠间距/细线，不堆实色卡片。组行轻透底/柔影，编辑删除/居中拖柄融入行内，焦点可辨 |
| 滚动与状态 | 内容独立滚、切分类归顶，标题/导航保留；外观状态/恢复默认和站点手动栏占底部布局，不盖字段/焦点；其他表单统一动作区，状态恒占位，不反复增删草稿说明 |
| 项目编辑 | 宽820px，基础两列、图标类型/内容/底色三列，上传紧随内容；局部Form token收间距，不缩字号/控件。≤640px单列，常见桌面初始完整；短窗/错误/上传增高只滚内容，标题/动作始终可达 |
| 窄屏表单 | 320px开关仍左标签/右开关同行、标签可折行；复杂表单双列转单列，不重复窗口/分区同名标题。空图库明确上传、无无意义分页，手机账号操作列固定 |

外观的主题/标识/壁纸预览随草稿；窗口底仍用已存壁纸。预览共首页图层/人工色/遮罩，以窗口比例缩小并等比换算模糊/扩边，示例不承诺首页布局。图层即时更新，分析延迟 **160ms** 合并、同图复用、状态按最大高度占位，加载/失败/不可分析有短说明，不挤滑块。长名省略带全文提示，坏图回首字符、换址恢复；主题选项中英窄窗均可操作。

自动保存反馈只展示真实聚合状态，保存/离页契约见[前端编辑约定](frontend.zh-CN.md#页面入口与编辑约定)；模糊/暗度0–10档但旧内部值不量化。监控高级配色默认折叠、键盘可展，色块辅助、输入仍支持完整CSS色值。访客/共享/覆盖/即时生效范围在所属分区说明，不另堆提示卡。

读取失败用同表面状态区：摘要/建议/重试，管理员按需展开原文；首次错不同时显示空数据，刷新/局部错保留可用内容。Docker局部提示紧凑左齐，手机动作换行，长技术详情折叠/限高/可换行，列表/资源/日志/鉴权共用。
