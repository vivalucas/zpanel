# 功能边界

当前能力与页面操作由 [React 前端说明](../docs/frontend.zh-CN.md) 和 [验收矩阵](../docs/frontend-audit.zh-CN.md) 统一维护。

核心约定：导航分组与排序、图片/文字/Iconify 图标、内外网地址、搜索；设置页面 Hash 路由，管理员与普通/匿名用户入口不同，服务端最终鉴权。外观、搜索与监控及个人资料自动保存，失败保留草稿并可重试；正常内部离页等待保存，失败/无效/上传及密码草稿继续保护。站点代码/安全设置、密码与实体编辑显式提交。

图库引用查询/替换只处理有权限的引用，不能误删被使用文件。导入默认追加、显式覆盖，服务端事务+稳定 requestId 幂等。导出不含二进制图片或整个账户数据。Docker 操作需要管理员和宿主机权限。

PWA 是可选静态界面缓存，不提供离线业务写入。自定义 CSS/JS 是管理员功能；安全模式用于恢复，不能将其简单当成已移除功能。
