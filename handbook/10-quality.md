# 质量与验证

加载边界及派生资源回归由 `tests/e2e/loading-performance.spec.ts`、`src/app/antdLocale.test.ts`、`src/locales/index.test.ts`、`src/lib/staticCompression.test.ts` 和 Go router/storage/API 测试共同覆盖。资源预算须有实际脚本与正字节数，延迟模块须证明成功到达，不能用弹层未出现代替取消验证。生产构建和浏览器回归仍是分包修改的必要检查；本地复访/合成弱网结果见 01，真实图片、生产链路及实机性能仍须另测。

公共首页壳的慢鉴权/代码/外观、真实时钟、无私有读取、路由竞态和浅深/高对比布局见 `home-startup.spec.ts`；不能用普通占位替代真实时钟，或提前挂载个人查询来缩短等待。代码失败验收须实际拒绝首页、菜单、编辑、排序及监控模块的请求：初始失败保留公共壳与时钟并可刷新；可选模块失败保留首页及导航，关闭/取消后焦点可恢复，迟到结果不重开。可选失败专项见 `home-optional-modules.spec.ts`；慢请求最终放行不能代替失败验证，刷新动作必须验证实际页面重载，当前执行结果见 01。

首页复访与请求期限另见 `home-cache.spec.ts`、`homeCache.test.ts`、`api.test.ts`：必须在新鉴权成功后才恢复展示数据，旧快照在首次重验前不进入可写表单；覆盖新标签页、撤权、切账号、设置入口和真实响应体中断。首页图标派生与原 URL 保留见 `home-image-loading.spec.ts`、`displayImage.test.ts`。WebP 回归须核对列表无 `thumbnailSrc`、首页不请求派生 URL，直接带缩略图参数访问仍返回原文件，且不生成派生缓存；Go storage/router/API 测试负责服务端边界，不能只验证浏览器显示成功。弱网结果应记录带宽/延迟、缓存模式、API 模拟与真实范围，不把合成样本速度承诺为线上收益。

全页 UI 优化专项与当前浏览器矩阵见 [前端验收](../docs/frontend-audit.zh-CN.md) 的当前回归入口。除首次读取失败外，还须覆盖有缓存的后台刷新失败、保存成功后重取失败、401/403/业务鉴权拒绝隐藏缓存与操作，以及上传途中手改后再改回原值；普通同值比较不能代替草稿版本。单图模式还须验证旧失败重试与新文件上传互斥，多文件图库保持并发。界面控件需同时检查可访问名称、320px 实际行布局和浮层动画完成后的视口范围。

原生链接的新标签页快捷键回归使用 Playwright `ControlOrMeta`，随运行平台选择 Control 或 Meta；不能将 macOS 的 Meta 写死到 Linux CI。中键、修饰键和普通点击的 iframe 行为仍分别验证。

壁纸对比度回归在取样前等待空分组按钮的前景色达到标题的目标色，避免将 Ant Design 颜色过渡当作最终对比度；人工黑白色的自动模式检查至少 4.5:1，自定义色不可达时检查不恶化原最差对比，无法可靠解析时检查保留原图。默认模式验证无额外整图遮罩及局部控件对比，不能要求任意壁纸的透明文字都达到该保证。持续的颜色或遮罩错误必须失败，预览与首页需比较同一裁切、模糊及遮罩后的实际像素。
