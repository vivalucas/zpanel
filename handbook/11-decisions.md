## 产品与开源边界

**依据**：2026-05-20 产品决策、2026-05-21 独立仓库发行、2026-09-27 产品定位更新；已采用。

ZPanel 使用独立产品定位、仓库、数据格式和发布流程。代码、界面及文档介绍当前 ZPanel 能力，关于页提供项目地址与前后端版本；导入导出只维护 `.zpanel.json`，新增格式迁移另行设计。按用户已确认要求，LICENSE 保留 MIT 正文及 ZPanel contributors 版权行；此修改未进行代码来源或许可适用性审计。

导航、个性化、多账号、图库和 Docker 等面板能力直接进入开源版，不引入付费限制，不复制闭源代码或实现商业商城/授权后台。配置优先复用既有实体，快速账号切换是浏览器本地能力，Docker 管理仅对管理员开放。未来插件/应用市场或不同租户模型需要另行评估。早期“Go 未编译、Docker 未验证、没有安全模式”的初版不足已被后续实现和发行验证取代，不能继续作为当前待办；实机缺口见 01。

## 仓库只保留 main 分支

**依据**：2026-09-28 用户约定；已采用。

用户明确要求仓库严格只保留 `main`。开发、提交和推送直接在 `main` 进行；不创建临时开发分支或工作树。已移除自动创建更新分支的 Dependabot 配置，依赖更新改由人工审查后提交到 `main`。代价是需要主动检查依赖与安全更新；若以后恢复自动更新分支，须先由用户改变该分支约定。`main` 的 CI 检查继续运行。

发布前核对 README、CHANGELOG、版本源、镜像和 Release 一致性。handbook 随仓库跟踪；早期“仅在本地忽略”已被现状取代，不因此删除已跟踪文件或改写 Git 历史。提交、同步与部署授权边界仍以 AGENTS 和开发导航为准。

## 管理员能力与安全数据边界

**依据**：2026-05-22 能力边界、2026-09-12 修复及 2026-10-07 获批优化；当前实现已采用，后者收紧早期私网 favicon 规则。

- 管理员配置 CSS/JavaScript、公开上传资源与 Docker 管理属于自托管能力；默认登录信息公开，首次登录后更改。不能因功能是设计意图就扩大调用权限。自定义脚本仍缺 CSP 纵深；localStorage 会话存储的保护依赖防 XSS。多租户或非管理员权限扩展须重新评估。
- 私网 favicon 默认关闭，仅管理员可用 `[network] favicon_private_origins` 中精确 scheme/host/port；普通账号只访问公网。每次连接、重定向和 DNS 实际连接均校验，环回/链路本地/云元数据始终拒绝；真实 NAS 仍待实测。
- 默认不信任代理，可信地址须显式配置，不能恢复旧全网信任。导航仅允许网页协议及相对地址；若需 ssh 等协议，须另行评估白名单，不能直接放开任意协议。
- 会话撤销、账号状态/角色、验证码及公开模式直接读取数据库，不依赖 Redis 删除成功；代价是每次鉴权读取，适用于个人服务器规模。`last_seen_at` 最多每五分钟更新，未来性能优化不得恢复旧权限缓存。
- 配置读取不自动补写默认值，安全配置损坏/数据库错误拒绝相应操作。外观损坏可显示回落与提示，用户调整触发保存或明确修复才写回；站点和验证码同一事务，必须验证回滚及回读。
- 服务端通过专用字段确定归属，不绑定 ORM User 关联；读取仅返回所需资料。密码写入与会话撤销原子，标题使用 200 字符及既有 AutoMigrate 扩容，真实 MySQL 扩容仍待验收。
- 2026-05-22 移除没有存量用户来源的 MD5 密码兼容，仅使用 bcrypt；该决定不表示可以忽略后来形成的有效数据兼容要求。新密码与登录统一 72 个 UTF-8 字节上限。
- 资源引用在既有 URL 尚未迁移时按业务数据核查，不能依赖空引用表；多副本协调及完整增量索引另行设计。导入用事务和持久幂等收据，默认追加、覆盖显式确认；配置导出不含二进制上传，完整恢复需要配置和数据。

已修复问题和证据入口见 [15 全项目评审](15-project-review.md)，不把历史复核结论扩大为当前平台验收。

## 同账号图片上传去重

**依据**：2026-10-27 用户确认；本地实现完成，未发布。

图片上传复用既有文件实体及 SHA256/Size，仅合并同账号、同可见性/用途/存储的有效上传，不引入跨账号物理对象共享，以保持图库归属和删除权限。已有重复及空指纹必须兼容，不增加会拒绝存量数据的唯一约束，不自动改写或删除历史文件。接口契约见 [06](06-api-design.md)。

客户端上传和实际大小/指纹计算在持锁前完成，避免慢上传阻塞设置；候选磁盘内容校验、复用和新建与既有删除/引用写入共用一把锁。数据库指纹不能证明原文件还在或未损坏；命中前须校验实际字节，失败不能返回已失效的旧 URL。该协调只覆盖默认单进程，多副本部署须另行设计；服务器完成收取后才去重，节省持久化空间但不省上传流量。

## Docker socket 与实际服务身份

**依据**：2026-10-25；已随 1.2.7 发布并完成 M5 验证。

Docker CLI、宿主 Docker 正常或 Compose `group_add` 都不能单独证明功能可用。`su-exec zpanel` 按容器组文件重置补充组；入口仅为已挂载 socket 且启动组列表包含的 socket GID 建立用户组成员，不继承其他附加组，不以 root 服务或放宽宿主权限替代。启动主组也属于判据，不能误写为只识别 `group_add`。

BusyBox `addgroup -g` 编译上限可能小于 Linux 合法 GID 范围；数值校验后以安全名称写组文件，已有组复用。Docker 可选组准备失败告警并继续站点启动，基础初始化失败必须退出；条件函数中的错误不能只靠 `set -e`。合成回归之外，须在正式镜像隔离验证 BusyBox/su-exec、实际进程 UID/Groups 与 Docker 读取；其他生产容器不能作为启停测试对象。旧 1.2.6 临时入口挂载升级时移除，生产状态见 01。

## 部署一致性与恢复证据

**依据**：2026-10-26 发行及 M5 校验；已采用。

发布前后严格核对 SQLite schema/逻辑行、配置和上传权限。GORM 启动迁移可能重排 sqlite_sequence 的隐含 rowid，1.2.8/1.2.9 同条件对照已确认；仅排除该内部表的无业务语义 rowid，仍核对 name/seq 和业务表行号。清单格式变化须重新生成前后两份，不能忽略整个表或只检查启动正常。

生产 UI 查看属于启动校验之后的另一阶段：认证中间件可能更新 session 的 last_seen_at/updated_at，须逐列确认，仅在该阶段限定比较例外，不能豁免整表或把例外用于迁移校验。并行用户操作产生业务配置差异时须列出具体键、保留来源不明的新值并继续核对其余字段，不以恢复整库覆盖活动。

备份/回退需要配套数据与部署配置，不能只改旧镜像；合成脚本检查和升级成功不代表完整生产恢复演练。备份、审计或旧镜像删除后必须标为不可用，不能继续将历史路径写成现成恢复材料。实际保留情况仅维护在 01。

## 首页布局、人工文字与壁纸

**依据**：2026-10-22 至 10-26 用户反馈；以下为最终有效约定，具体尺寸和回归见 [视觉规范](../docs/ui-design.zh-CN.md)。

首页以壁纸、透明标题/分组、留白和独立图标呈现，设置玻璃窗口不复用于首页。2026-10-25 的左侧名称/时钟、右侧搜索替代居中堆叠；窄屏或窄内容宽度自然堆叠，与分组左沿对齐。保留原边距数值和 0 语义，顶部按视口高度设比例上限，不能通过改默认值或悄悄迁移显式 10 来替代兼容。监控、提示和错误保持文档流。

2026-10-26 最终反馈取代此前“按壁纸自动选黑白字”的方案：默认固定白字配细黑描边/柔阴影，既有 iconTextColor 手选黑白或高级自定义色；空/缺键/旧默认仅显示为白，读取不写回。壁纸裁切、主题及失败不能改变人工颜色，图标内部及显式时钟/监控颜色独立，系统高对比使用成对系统实底/字色。

`wallpaperAutoContrast` 缺省关闭，取代更早隐式全页遮罩；原暗度/模糊值保留，旧壁纸可能变亮。开启后仅按人工颜色求解遮罩，不再选择字色；真实自定义 RGBA 不可达时不得恶化原最差对比，继承、系统色等不能可靠解析的值保留原 CSS 和原图。采样须保留可见像素局部亮暗，按实际 fixed 区域、cover 裁切、底色合成和模糊计算，原色边界不能代替模糊后混色，平均缩略图或 innerWidth/clientWidth 也不能推断实际显示。超大画布、跨域和不支持采样滤镜有明确回退，不上传像素；已有 JSON 承载开关，无新表/迁移，旧备份缺键不覆盖已有选择。

预览和首页共用图层与色彩计算；预览即时更新图层、延后合并分析、复用同图并固定状态区占位，不能因每次参数变化插入加载文案或挤动滑轨。回归须用真实指针同时核对几何、采样和松手保存，静态截图不能证明拖动流畅。

同日最终工具位置取代桌面右上/手机右下及页头预留：所有尺寸使用右下水平工具条，页头恢复完整配置宽度。回顶加入其左侧，出现仅向左扩展，保留迟滞、键盘焦点和减少动态效果；原入口不得跳位。固定层可达性须核对交叠、实际命中、页脚与键盘路径，单独 visible 或无横向溢出不足以证明。

## 自动保存与设置窗口

**依据**：2026-09-27 设置窗口、2026-10-24 全页优化及 2026-10-26 日常偏好；后者取代外观/组件/资料的手动提交约定。

外观、搜索与监控、昵称和头像停改后校验并自动保存，拖动或上传期间暂停，按表单串行，旧响应不能清除新草稿。读取不补写、不量化旧值，滑块仅统一显示刻度。同页多分区的成功反馈必须聚合全部状态：任何失败不得被另一分区成功覆盖，仍有等待/无效/未保存草稿时不能笼统提示已保存；确认放弃离页清理持久错误。内部离页等待正常保存，失败/无效/上传/密码草稿继续保护。站点事务含验证码及 CSS/JS，半成品不能自动执行，整页继续手动提交；密码、实体和数据操作保持明确动作，恢复默认确认后自动保存。

设置使用单一悬浮玻璃窗口、融入侧栏和独立滚动，手机显示同组分类选择器，仍是普通 Hash 路由页面。保存状态/动作区独立占布局，不遮挡字段焦点。移除亮白轮廓和重复大卡片，低频配色折叠，厚磨砂用于密集浮层，并提供低透明度/高对比回退。320px、侧栏断点、长名称、失效图片和字段可访问名称均属正常验收边界。

暂时刷新失败保留本会话可用缓存，鉴权拒绝必须隐藏缓存和操作；首次失败重试时不能仅依赖会被 refetch 清空的瞬时 error，挂起期间保留错误反馈及按钮状态，完成后才由新结果接管。自动保存先取消旧读取并更新缓存，不逐次重取；手动保存重取失败也不能恢复旧值。搜索默认项按完整对象匹配并兼容旧 URL，不为相同 URL 新建实体；仅改头像可保留既有非空昵称，真实改名仍按原限制。

## 图标、菜单与编辑交互

**依据**：2026-10-24 至 10-26；已采用，参数统一维护在视觉规范。

图标不自动去底或 cover 裁切，旧白色无法区分默认与用户选择，不能按值清空；新空背景使用独立轻磨砂，原显式底色保留，编辑预览复用组件。固定 flex 底座，验证横竖图实际端点像素，不能只断言 contain；换类型/地址须重置失败。磨砂先写 `-webkit-backdrop-filter` 后写标准属性，生产构建的 computed style 必须核对，源码声明不代表运行生效。

图标及详情卡悬停仅加深阴影，不位移/缩放；2026-10-25 方案移除覆盖图标的菜单按钮，保留右键/菜单键/Shift＋F10 及原权限，关闭菜单或编辑后按稳定应用 ID 回焦。触屏仅接收浏览器 contextmenu，不新增计时长按识别；iOS 入口缺口保留，事件模拟不能代替实机。名称提示只补足实际省略的文字，不显示网址，不按字数猜测，尺寸/字体改变后重测。

导入只在设置入口。显式菜单地址不走内外网回退，快捷打开不改存量打开方式；主地址严格对应表单“地址”，两地址去空白后相同时合并，不扩展为 URL 归一化。主操作与带文字三列快捷项采用共享 Menu 键盘语义，管理项在分隔线下；保留原生链接修饰键、中键、Shift＋右键和页面空白菜单，复制失败有手动路径，迟到结果服从生命周期。

项目编辑采用两列基础字段和集中图标区，不能为了桌面一屏缩小常规控件、删字段或裁切错误/上传；手机短窗口仅内容滚动，固定动作可达。减少动态效果的全局 transition-duration 必须为 0s，给所有元素非零极短时长会使浮层临时 left/top 测量读到屏外旧坐标；关键帧和按钮加载图标限定 width/opacity/margin 过渡保留结束事件，避免残留 loading，不为定位属性设置例外。回归实际滚动长选择列表并保存，不用强制点击掩盖遮挡。

## 前端生命周期与确认边界

**依据**：2026-10-23 专项及后续自动保存；证据见 [16](16-frontend-event-review.md)。React 从 1.2.0 起替换旧 Vue/Pinia/Naive UI，不并行维护旧前端；原质量条目已合入 [10](10-quality.md)。

- 页面请求同时绑定发起会话与组件生命周期，匿名登录也不例外；调用方取消信号继续有效，监听在结束时清理。客户端取消不代表服务端写入回滚，不依赖新的 AbortSignal 静态便利方法。
- 确认框属于发起页面，离页销毁；已确认放弃的账号转换先同步放行 blocker，再切会话和导航。受保护入口使用 Router 导航，外部链接保留浏览器行为。
- 上传期间外观/资料暂停自动保存、实体禁提交，保存期间不接新上传；异步结果按字段草稿版本写回，A→B→A 仍是新编辑。favicon 结果还核对目标 URL/类型；本地文件只接受最后选择，确认时冻结预览。
- 语言失败回退服从最新选择；安全模式根据本页是否曾运行脚本决定刷新，不能以当前脚本为空推断旧副作用消失。
- 复核实际回调与第三方行为，不仅凭 disabled 外观判断；运行回归、静态检查和实机缺口分别报告，同轮协作自查不能称独立验收。

## 页面加载与派生资源

**依据**：2026-10-27 加载评审及用户授权；本地实现，验证状态见 01。

页面代码可在鉴权期间下载，账号数据仍受会话和权限约束；已下载的组件直接复用，不把一次完成的导入再变成首屏等待。首页普通展示与编辑、菜单、拖拽及监控分开加载，分区域呈现保持错误、空数据和权限拒绝的区别。可选模块失败由所属局部表面承接，保留首页和导航，提供关闭/取消及刷新页面；局部失败不能交给整页错误边界而移除仍可用内容。取消回到原触发点，自动加载的监控回焦首页名称。延迟加载必须验证失败、取消、键盘焦点及迟到结果，不以请求数量越少或分包越多作为目标。

首页公共布局与本机时钟可在鉴权期间展示，以减少只有加载动画的等待；公共壳必须轻量独立于完整 Home 模块，且不提前读取/恢复个人快照或查询。通用占位不能伪装成可操作的导航，鉴权/外观读取失败和初始 Home 代码失败均保留标题/时钟。读取失败可重试，代码失败明确提供刷新页面，因为同一页面中的失败导入可能被浏览器/React 缓存，不能用重置边界冒充可靠重试。设置与登录维持各自边界。时钟共用正式首页实现、正确清理计时器，并避开状态播报区域。此呈现优化不承诺省略 HTML/脚本传输或实现离线身份验证。

反复打开主页可在新鉴权成功后恢复同账号/角色的有限展示快照并后台重验，不能恢复旧鉴权、跨账号或公开模式数据。快照只保存约定展示字段，损坏/超龄/超限/存储失败不阻断网络路径，退出及撤权及时剔除。持久快照在首次重验前不得参与编辑、排序或整对象写回；直接打开设置不恢复，从首页进入设置也清除未验证的内存值，防止自动保存取消重验后覆盖另一设备的新配置。具体预算与回归见前端开发/验收文档。

验证状态必须可订阅，不能依赖业务数据引用变化来恢复控件；TanStack 结构共享会让相同响应保持同一引用。回归须包含「后台返回完全相同数据，添加/排序和搜索引擎仍恢复可用」，不能靠延长等待或取消编辑保护掩盖状态通知缺失。

只读请求可用有限客户端预算结束持续加载，并区分超时和主动取消；期限覆盖响应体读取。上传和业务写入不默认套相同超时或自动重试，取消等待不意味着服务端回滚。

压缩在构建期完成，服务端协商已有表示，不逐请求消耗压缩 CPU；内容哈希资源可长期缓存，HTML/worker 等可变入口需重新校验。原文件和编码表示逐字节对照，并覆盖 HEAD、304、Range 及可选 PWA。图库缩略图复用原文件实体和公开 URL 边界，放入独立可重建缓存，不改原图/引用或依赖新表；方向、格式、资源上限及收益不可靠时保守回退。

同源普通 PNG/JPEG 上传图标可复用缩略图，展示派生不改配置原 URL，WebP、外链/参数/动画/矢量及全屏壁纸保留原图。WebP 的无损解码器可依据流内变换/编码参数分配远超容器尺寸估计的内存，检查画布与帧尺寸不足以建立受控内存边界；在有可证明的解码预算或隔离方案前，服务端完全跳过 WebP 缩略图解码，不改变其原图上传和展示。PWA 预缓存清单必须经实际 Go HTTP 路径和 worker 激活验证；需要的固定入口逐条注册，不为修复缺项开放任意目录。
