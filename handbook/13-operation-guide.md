# 操作指南

用户安装和使用从根 README/README.zh-CN.md 开始。详细部署见 08，设置与菜单行为见 docs/frontend.zh-CN.md。

配置导出适合导航/外观迁移；完整恢复须另备份配置和数据。自定义脚本异常时使用 safeMode 参数进入站点设置恢复。不要用旧 Vue 菜单路径或旧根用户容器方案操作当前版本。

空分组可直接「添加第一个应用」；配置导入从「设置 → 导入与导出」进入。应用可只填内网地址。右键应用，可按地址打开、新标签页/内嵌打开、复制地址，以及在有权限时编辑/删除。快捷打开不修改已保存的打开方式。中键/修饰键维持浏览器行为；Shift＋右键或右键页面空白处使用浏览器菜单。图标上不显示菜单按钮；键盘聚焦应用后按菜单键或 Shift＋F10 打开菜单，用方向键选择、Esc 退出；触屏浏览器支持长按菜单事件时也可进入。当前分组排序时菜单暂不可用。复制不可用时会展示完整网址供手动复制。

图标悬停不显示网址提示；应用名称被省略时，悬停名称文字可查看全名，已完整显示的名称不弹提示。

右键菜单中的「主地址」对应编辑表单的「地址」；主操作下方可直接选择新标签页、内嵌或复制。同一网址同时填在主地址与内网地址时，菜单只显示一组操作；两者不同时分别显示。

删除分组会显示应用数量，可选择移至其他分组或连同应用删除；最后一个分组不可删除。导入前显示新增或替换的数量，覆盖仍需确认。

图片上传显示逐文件状态，失败可重试，单文件最多 10 MiB。外观配置损坏时通过「修复外观配置」核对默认值后点击修复或调整设置；单独图库上传不改变外观，外观页上传成功会自动保存。私网 favicon 的管理员配置见 [07 环境](07-environment.md)。

风格设置可手选首页白字或黑字，默认白字配细黑描边阴影，文字稍加粗；也可展开自定义颜色。有无壁纸时均保持选择，不随主题或壁纸自动换色。首页设置和内外网入口统一在右下工具条，可用 Tab/Enter 操作；向下滚动后左侧出现「回到顶部」，点击回到页首，键盘焦点回到名称处。

壁纸模糊、暗度和自动对比度即时更新同窗口比例的预览，模糊与暗度统一为 0–10 档，松手停改后自动保存。默认关闭自动对比度；关闭且暗度为 0 时不额外改变整图亮度，开启后只用遮罩配合所选文字，不换字色。复杂纹理下可调整暗度或开启此开关；任意自定义色仍可能无法达到目标对比，无法可靠分析的颜色不额外加罩。旧数值保持，关闭旧自动遮罩后可能变亮。监控颜色可在各卡的「高级配色」中展开，支持完整 CSS 色值。

外观、搜索与监控、昵称和头像停改后自动保存；失败保留输入，可点重试，字段无效须先修正。搜索与监控同页有任一失败时保留错误，全部已修改分区保存成功才提示「已保存」。刚改完内部切页会先等保存，上传、失败或无效草稿仍受保护。站点设置、密码与项目等编辑保持明确提交及草稿保护。图片上传中继续手填地址会保留后来的输入，单图上传期间另选文件和旧失败重试暂不可用。

首页导航、监控、外观及站点已有内容短暂刷新失败时保留上次数据并提示重试，不能把过期监控值当作当前实时值。
