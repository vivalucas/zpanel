## 当前阶段

## 本轮已完成

- 验证码尺寸限制与独立 IP 限流。
- 显式可信代理配置，默认仍不信任转发头。
- 编辑/删除至少保留一个启用管理员；角色变更事务与管理员行锁。
- 密码更新与 session 撤销原子提交；登出撤销失败不再返回成功。
- 图片引用按现有业务数据核查，图库可查看用途、替换本人引用；不泄露他人私有标题。相关写入串行化，并拒绝引用已删除的本地图片。
- 导入改为一次服务端事务，支持追加/覆盖、请求幂等，前端增加预览、重名提示、配置备份边界说明。
- 导出任何分组/图标读取失败即停止，保留排序值 0。
- Docker 命令取消、30 秒超时、2 MiB 输出上限；行级操作状态与停机/重启确认。
- favicon 使用最终页面地址解析相对 URL，保留查询参数；页面 2 MiB 和候选 20 项限制。
- 前后端过滤危险导航协议，搜索引擎模板校验、编辑 Enter 隔离。
- 壁纸保存成功后再应用，失败保留可重试草稿；搜索配置保留未保存提示。
- 新增针对性 Go 与前端回归检查，并将前端回归脚本接入 CI。

## 待处理 / 限制

- Docker 实机权限与不同宿主机版本兼容性仍需验证。
- MySQL 实机并发与 Redis 多实例缓存一致性未联调；当前资源写入互斥针对单进程部署，多副本共享数据库/上传目录需要另行设计跨实例锁。
- 资源用途查询为按需扫描现有 URL/文件 ID 数据，适合当前个人服务器规模；大数据量可后续迁移到完整增量引用索引。
- 配置 JSON 不包含上传文件；完整迁移仍需备份 conf/data。
- 非中英语言保持此前基线翻译策略，尚未完成母语级文案。
- 前端主入口仍有大 chunk 提示；custom 静态资源存在既有构建提示。
- 知识库目前已被 Git 跟踪；不再把旧“仅本地忽略”描述当作当前事实，本轮保留现有跟踪规则。
